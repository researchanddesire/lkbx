# Lockbox Hardware

This directory contains the Lockbox open hardware files.

## Contents

- `bom.csv` - top-level Lockbox assembly BOM with 3D-printed parts, PCB
  sourcing, off-board hardware, accessories, packaging, source links, and
  supplier details.
- `pcb/` - KiCad PCB source, schematic sheets, board layout, local symbols and
  footprints, component STEP models, datasheets, and production fabrication
  exports through PCB revision `v1.4`.
- `cad/` - mechanical enclosure CAD landing zone.

See `hardware/pcb/README.md` for PCB design notes and revision history.
